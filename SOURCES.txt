The USB transport, Windows spool integration and UI are included in app/.
The CAPT job sequencing in app/capt.py was ported from captdriver.
Protocol and compressor copyright Alexey Galakhov and contributors.
Additional protocol contributions include Alexei Gordeev.

Build the included ARM64 DLL from source, using Zig 0.15.2 as a C compiler.
Run this command from the extracted package directory.

zig cc -target aarch64-windows-gnu -O2 -shared -s -Icodec codec/codec.c codec/hiscoa-compress.c codec/hiscoa-common.c -o app/hiscoa.dll

The setup/wheels directory contains the original Windows ARM64 wheels for
Pillow 13.0.0 (CPython 3.12) and pypdfium2 5.14.0 with their license notices.
setup/requirements.txt records the SHA-256 hashes published on PyPI.
https://pypi.org/project/Pillow/13.0.0/#files
https://pypi.org/project/pypdfium2/5.14.0/#files

Setup gets the Python Software Foundation's ARM64 Windows installer from the
WinGet community source. On PCs missing WinGet, it can register App Installer
or deploy Microsoft's signed release bundle and required ARM64 frameworks.
https://github.com/microsoft/winget-pkgs/tree/master/manifests/p/Python/Python/3/12
https://github.com/microsoft/winget-cli/releases/latest
